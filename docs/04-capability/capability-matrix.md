# 能力矩阵（MCP 商品上传）

版本：v1.2  
更新时间：2026-04-03（Asia/Shanghai）  
责任模块：orchestrator-api / chrome-mcp-worker / rule-engine

## 状态说明

1. `Planned`：已定义未开发
2. `In Progress`：开发中
3. `Ready`：可用于生产或灰度

| 页面执行 | 页面导航 | 进入商品管理-新建商品并等待关键元素 | In Progress | P0 |
| 页面执行 | 稳定选择器映射 | 主选择器+备用选择器自动回退 | In Progress | P0 |
| 页面执行 | 真实桥接执行 | 通过 Chrome 远程调试桥执行真实页面动作 | In Progress | P0 |
| 页面执行 | 字段自动填充 | 类目、品牌、名称、规格、价格、描述填充 | In Progress | P0 |
| 页面执行 | 图片上传 | 批量上传主图并校验上传成功标识 | In Progress | P0 |

| 运营支持 | 执行报表 | 输出批次成功率、失败分布、重试统计 | Ready | P1 |

| 可维护性 | 自动故障排查 | 失败后自动调起 Codex 分析并修复 | Ready | P0 |
